A sleek, modular desktop application written in Python that provides quick clinical health metrics at a glance. Originally conceived as a text-based terminal application , it has been refined into a gui application and exported as an .exe file thePython's standard Tkinter library to offer a modern, dark-themed user interface.

# How to run the app.
1) Simply navigate to the dist folder and download the Medcial Calculator.exe file and run it.
